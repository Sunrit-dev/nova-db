# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in NOVA DB, please send an email to `security@novadb.dev`.

Please do not open public GitHub issues for security vulnerabilities. We will review and acknowledge all reports within 48 hours.
